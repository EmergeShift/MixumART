# 界面结构

界面是 React 19 + TypeScript + Vite，手写 CSS，沿用 mixumOS console 的设计 token。
不引组件库，避免宿主机应用为了几个表格引入一整套运行时。

## 1. 窗口结构

```
┌────────────┬──────────────────────────────────────────────┐
│ mixum      │  宿主机环境                       macOS · ... │  ← 顶栏：页面标题 + 宿主信息
│ Agent Env  ├──────────────────────────────────────────────┤
│            │                                              │
│  环境      │  运行时                                      │
│  容器      │  ┌──────────┐ ┌──────────┐ ┌──────────┐     │
│            │  │ Docker   │ │ WSL 2    │ │ Apple    │     │  ← 环境卡片
│            │  └──────────┘ └──────────┘ └──────────┘     │
│            │                                              │
│ v0.1.0     │                                              │
└────────────┴──────────────────────────────────────────────┘
```

- 左栏固定 204px：品牌、导航、版本；
- 顶栏 52px：当前页标题 + 宿主信息；
- 内容区独立滚动。

## 3. 状态与数据流

- `App.tsx` 持有**全局**状态：宿主信息、三个后端的状态、全局错误；
- 视图持有**局部**状态：`Containers` 自己管理选中的 runtime、容器列表、加载与错误；
- 所有请求经 `src/api.ts`，组件里不出现命令名；
- 错误统一渲染成顶部红色条（`errorText()` 把 `unknown` 转成字符串）。

约定：

- 状态查询在挂载时执行一次 + 用户手动刷新，**不做后台轮询**；
- 只读阶段的写操作按钮**不显示**，而不是显示后报错；
- 加载态用文字（`检测中…` / `读取中…`），不用骨架屏——桌面工具不需要。

## 4. 设计 token

定义在 `src/styles.css` 的 `:root`，与 `mixumos/console/src/styles.css` 一致：

| 变量 | 值 | 用途 |
|------|-----|------|
| `--bg` | `#f4f4f2` | 窗口底色 |
| `--panel` | `#ffffff` | 卡片、表格、侧栏 |
| `--panel-2` | `#fafaf8` | 表头、悬停 |
| `--border` | `#dcdcd6` | 主边框 |
| `--border-soft` | `#e8e8e2` | 分隔线 |
| `--text` | `#22221f` | 正文 |
| `--muted` | `#77776e` | 次要信息 |
| `--accent` | `#3a6ea5` | 选中、链接 |
| `--ok` / `--warn` / `--err` | `#3f7d44` / `#a5703a` / `#a53a3a` | 状态色 |

字号：正文 13px，表格 12.5px，辅助信息 11.5px；等宽信息用 `--mono`。

## 5. 文案约定

- 中文、陈述句、不用感叹号与 emoji；
- 状态词固定：`可用` / `未安装` / `未运行` / `不可用`；
- 容器状态固定：`运行中` / `已停止` / `已创建` / `已暂停` / `未知`；
- 技术标识（`apple_container`、命令、路径）用等宽字体，不翻译。

## 6. 与 console 的关系

console 是**容器内**的控制台（任务 / 窗口 / 快照），本应用是**宿主机**的管理器。
两者共享视觉语言，但不共享代码：

- 相同：配色、字号、边框、状态色、等宽字体；
- 不同：console 用顶栏 Tab，本应用用左侧导航（桌面窗口更宽）；
- M4 迁入任务/窗口/快照视图时，交互按桌面习惯重做，不直接复用 console 组件。
